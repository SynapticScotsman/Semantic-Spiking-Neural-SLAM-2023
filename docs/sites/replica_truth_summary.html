context

Where this sits against published work — different metric, stated honestly

The scene-graph systems evaluate dense semantic segmentation on these same 8 scenes (GT-scored): ConceptFusion 24.2 mAcc · ConceptGraphs 40.6 · HOV-SG 38.1 · KeySG (2025) 45.8. Those numbers are a different task (label every point) and sit here for scale, not same-number comparison: semantic error is the whole field's bottleneck. ConceptGraphs' own query-style evaluation reports R@1 ≈ 0.59. The same-metric, same-data head-to-head is the pending ConceptGraphs run on these scenes (student GPU), scored by the identical script — at which point the frontend×backend 2×2 completes.

Protocol notes: GT = instance centroids backprojected from the vMAP semantic renders (same mesh, frame-alignment gate per scene); REPLICA→COCO name map with judgement calls stated (stool→chair, table→dining table); never-detected GT classes count as misses; success radius stated per column; per-scene belief-field photo inspectors accompany this page.
