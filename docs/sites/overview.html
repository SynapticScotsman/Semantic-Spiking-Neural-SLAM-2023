What the system is

A map you can add up

The map is a vector symbolic architecture: an object's appearance vector is bound to its location encoding by circular convolution, and every landmark is summed into one trace. Because the trace is a sum, two robots' maps merge by adding them — there is no graph to stitch and no correspondence step. The cost of that compression is that answers are approximate and everything is recovered by similarity rather than lookup.

The size does not grow with what the robot sees. A scene contributing 2,357 observations and one contributing 10,465 both produce the same 32 KB trace, because insertion is bounded per class rather than per observation.

Reading the numbers

Truth-R@1 is the fraction of ground-truth object classes whose top answer lands within radius r of a real instance, scored against instance centroids backprojected from the Replica semantic renders. It is an internal diagnostic, not a published benchmark's own scorer — raw accuracies are not comparable across scenes, because chance level moves with room size. Compare above-chance margins and within-scene orderings only.

Result · eight scenes

Where the failures actually are

Across all eight Replica scenes the memory grounded every class it was given. All five misses came from the frontend — the detector either never fired, or stored a wrong label or a wrong depth. On office1 the trace grounded a table from a single stored observation that the clustering backend discarded as noise.
